HOW TO USE THIS FILE
------------------------------------------------------------------------
1. Once RAM Search finds the raw 'current map ID' value while standing
   in a REAL, RECOGNIZABLE location (e.g. Oreburgh City), search for
   that number in the FLAT INDEX LIST at the bottom of this file.
2. Note which labeled group/run that index falls into.
3. That single confirmed point anchors the whole surrounding run --
   since entries within one run are contiguous and almost certainly
   represent the SAME city's buildings in a fixed order, you can often
   infer the rest of that run immediately.

IMPORTANT: several short codes (C01-C11, D05, D26, R21, R22, T02-T07,
W22) are REUSED in separate, non-contiguous runs later in the file --
almost certainly because Battle Frontier, the Underground, or Wi-Fi
areas have their own independent 'City 01, City 02...' labeling,
unrelated to the main Sinnoh overworld. Each occurrence is labeled
separately below (occurrence #1, #2, etc.) so they don't get confused.

  - The first 11 C## runs (indices 3-196) are the most likely candidates
    for Sinnoh's 8 gym cities + a few other major hubs, since C01's
    first occurrence includes a GYM building -- this rules out any
    non-gym town (Twinleaf, Sandgem, etc.) for that specific run.
  - NOT yet confirmed: the exact city name for any specific run.
    Needs one empirical RAM Search data point to anchor the sequence.

      (e.g. index 353 = "R207" = Route 207, exactly)
  - Our indexing has been cross-validated against 42 independently-researched
      hex offsets published by TCRF's Unused Maps article -- 41/42 exact
      matches (the one "mismatch" was TCRF displaying the same link text
      twice for two adjacent pages, D05R0116 and D05R0117, not an actual
      discrepancy). Our indexing scheme is now considered highly reliable.

BUG FOUND AND FIXED (this round): the location-grouping script used a fixed
2-digit prefix match for everything, which is correct for C##/D##/T##/L##
groups but wrong for routes/water-routes (3-digit numbers, e.g. "R201").
This silently bundled routes 202-209 (and similar ranges) as garbage
sub-entries inside Route 201's card instead of becoming their own cards.
Fixed. All 30 real Sinnoh routes (201-230) are now confirmed cleanly
separated in the tracker's location list.

not a known Sinnoh route number)" rather than presented as fact.

  - L01 = Verity Lakefront (confirms the earlier prediction, matching

STATUS: only 1 group left fully unidentified -- L04 -- plus the R232
anomaly (not a real Sinnoh route number, real identity unknown). Started
from 47 unresolved groups; both practically closed out now.

NOTE: the tracker's static starter location list (BLANK_TEMPLATE_SOURCE) was
rebuilt from this same mapname.bin data as of this update -- 86 cards, 499
warps, replacing the original hand-curated 90-card list. Poke Center floors
are merged into a single "Poke Center" entry per city (the 1F/2F/3F split
isn't a real randomizable warp, just fixed staircases). Multi-room Gyms
(Eterna: 2 rooms, Hearthome: 13 rooms, Sunyshore: 3 rooms) were kept as
separate entries, since those genuinely are distinct puzzle rooms in-game.
Groups whose extra entries were scattered elsewhere in the file as literal
continuations of the same room sequence (D22, D24, D26, D31, T02-T07, W22)
were merged across all their occurrences rather than only using the first.
